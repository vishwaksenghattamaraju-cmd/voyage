VOYAGE AI — OFFLINE MODE QUICK START

1. Extract this ZIP into a normal project folder.
2. Open that folder in VS Code.
3. Open Terminal > New Terminal (PowerShell).
4. If dependencies are not installed, run:
     python -m pip install -r requirements.txt
5. Start the app in offline mode:
     .\run_offline.ps1

If PowerShell blocks the script, use these commands in the same terminal instead:
     $env:DEMO_MODE = "true"
     $env:LLM_PROVIDER = "rule_based"
     python app.py

Open the local URL printed by Flask (usually http://127.0.0.1:5000).
No OpenAI, Gemini, Groq, or other LLM API key is needed.
The local dataset contains sample planning information; prices and availability are estimates, not live data.
